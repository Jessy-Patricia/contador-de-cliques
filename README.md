# contador-de-cliques

Projeto 5: contador-de-cliques  
click-counter-react

Aplicação React de contador de cliques desenvolvida para praticar conceitos fundamentais do React, como componentes funcionais, estado (`useState`) e manipulação de eventos. A aplicação incrementa o contador sempre que o botão é clicado.

---

## Objetivo

Praticar os conceitos básicos do React através da criação de uma aplicação simples de contador, trabalhando com:

- Componentes funcionais
- Gerenciamento de estado com `useState`
- Eventos de clique
- Atualização dinâmica da interface
- Estrutura inicial com Create React App

---

## Funcionalidades

- Exibição do valor atual do contador
- Botão para incrementar o contador
- Atualização dinâmica do estado em tempo real
- Interface simples e interativa
- Estrutura organizada em componentes React

---

## Tecnologias

- GIT
- HTML5
- CSS3
- JavaScript (ES6+)
